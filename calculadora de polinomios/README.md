# Calculadora de Polinomios

## Cómo usar el proyecto
 Recuerda siempre escribir el polinomio de manera ordenada.
🚀 [Abrir Calculadora de Polinomios](https://gian222.github.io/Uniminuto/calculadora%20de%20polinomios/)

*(Alternativa: Si deseas revisar el código fuente, puedes clonar este repositorio y abrir el archivo `index.html` localmente).*

## Descripción
Esta es una aplicación web desarrollada para aplicar métodos numéricos y cálculo diferencial mediante programación. El proyecto forma parte del portafolio académico de la carrera de Ingeniería de Software de la Corporación Universitaria Minuto de Dios (UNIMINUTO). La herramienta permite analizar polinomios ingresados por el usuario para encontrar sus raíces y puntos críticos.

## Características Principales
* **Cálculo de Raíces:** Implementa el método numérico de bisección para hallar la raíz de un polinomio evaluando intervalos mediante el ciclo `while` y la validación de cambios de signo.
* **Máximos y Mínimos:** Utiliza el cálculo de derivadas, la aplicación de la fórmula cuadrática y el análisis del discriminante para identificar los puntos críticos exactos de la función.
* **Validación de Datos:** Cuenta con manejo de errores algorítmicos, incluyendo el uso de valor absoluto para distancias y la identificación de polinomios sin soluciones reales.

## Tecnologías Utilizadas
* **JavaScript:** Lógica matemática, control de flujo y manipulación del DOM (`parseFloat`, `Math.abs`, `Math.pow`, `Math.sqrt`).
* **HTML5 / CSS3:** Estructura de captura de coeficientes (a, b, c, d) y presentación de resultados en pantalla.
