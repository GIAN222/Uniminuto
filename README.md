# Portafolio Académico - Ingeniería de Software

## Descripción
Bienvenido a mi repositorio. Este espacio está dedicado a compilar, organizar y documentar todos los proyectos, talleres y laboratorios desarrollados durante mi formación profesional en el programa de **Ingeniería de Software** de la **Corporación Universitaria Minuto de Dios (UNIMINUTO)**. 

El objetivo de este repositorio es evidenciar mi progreso técnico, mi dedicación a tiempo completo al desarrollo de software y la aplicación de buenas prácticas de programación en la resolución de problemas lógicos, matemáticos y de gestión de datos.

## Stack Tecnológico y Herramientas
Los proyectos alojados en este repositorio abarcan el uso progresivo de múltiples lenguajes, bases de datos y entornos de desarrollo, reflejando el plan de estudios de la carrera:

* **Lenguajes y Frontend:** JavaScript, Java, C++, Python, PHP, HTML5 y CSS3.
* **Bases de Datos:** Relacionales (PostgreSQL, MySQL, SQLite) y NoSQL (MongoDB).
* **Análisis de Datos:** R, RStudio y WEKA (modelos de clustering y árboles de decisión).
* **Entorno de Trabajo:** Visual Studio Code, WSL/Ubuntu y gestión por línea de comandos.

## Estructura del Repositorio
El repositorio está diseñado para crecer módulo a módulo, estructurando los trabajos en directorios independientes:

* `📁 Calculadora-de-Polinomios/`: Aplicación web interactiva para calcular raíces (método de bisección) y puntos críticos mediante derivadas.
* `📁 Bases-de-Datos/`: Ejercicios de modelado, consultas SQL y administración de datos.
* `📁 Estructuras-de-Datos-y-Logica/`: Algoritmos, diagramas de árboles y resolución de problemas algorítmicos.
* `📁 Proyectos-Integradores/`: (Próximamente) Entregables finales de desarrollo completo.

## Navegación y Ejecución
Cada directorio dentro de este repositorio contiene su propio archivo `README.md` individual. Allí se detallan las instrucciones específicas para compilar, ejecutar o visualizar cada proyecto en particular, así como una explicación técnica de la arquitectura y la lógica implementada.
